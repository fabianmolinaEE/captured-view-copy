## Dependencies and setup

Added runtime `@fix-webm-duration/fix` (with its parser dependency) for MediaRecorder WebM duration metadata. Added test-only `fake-indexeddb`. Gemini and Supabase use native HTTP; there is no new production SDK or analytics service dependency.

[README.md](../README.md) contains environment variables, local commands, a complete live-demo script and the exact Lovable provisioning prompt. [ARCHITECTURE.md](ARCHITECTURE.md) documents module responsibilities and component interfaces. The mission's explicit Google Gemini server integration is implemented directly; no private credential is sent to browser code.

Minimum remaining live setup: copy `.env.example` to `.env`, configure `GEMINI_API_KEY` and an accessible `GEMINI_MODEL`, restart, record a consented checkout and run real analysis. Non-local APIs additionally require `RESEARCH_ACCESS_TOKEN`. Shared persistence additionally requires Lovable to create the documented RLS-protected table and private bucket and configure its server secrets. Do not enter API keys in chat, screenshots, session fields or the Settings workspace-code field.
